[CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/) (public
domain dedication), which asks for no credit. The sources are recorded here so
it is clear where each came from and how to replace it.

`human.glb` is trimmed from the KayKit source by `scripts/fetch-human.mjs`: the
mesh, texture and IK control bones are dropped, and only the `Idle`,
`Walking_A`, `Running_A` and `Jump_Full_Short` clips are kept. The other two
are downloaded as published by `scripts/fetch-animations.mjs`.

## Models

| File                      | Source                                                             | Licence |
| ------------------------- | ------------------------------------------------------------------ | ------- |
| `public/models/human.zip` | Generated by `scripts/make-models.mjs` from the rig in `human.glb` | CC0     |
| `public/models/fox.zip`   | Generated by `scripts/make-models.mjs` from the rig in `Fox.glb`   | CC0     |

Each voxel figure is a blocky approximation of its source rig — one box per
bone, drawn where that bone rests — so it can be hung off the skeleton with
"Auto-bind". No third-party art is used in them beyond the joint positions of
the CC0 rigs above.

## Regenerating

```sh
pnpm fetch:animations   # RobotExpressive.glb and Fox.glb
pnpm fetch:human        # downloads and trims KayKit Barbarian -> human.glb
pnpm make:models        # builds public/models/human.zip and fox.zip
pnpm make:assets        # all of the above, in order
```
